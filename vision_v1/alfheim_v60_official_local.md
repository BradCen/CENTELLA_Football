# Official Alfheim V60 local run

This benchmark uses the official native camera segments 0059-0061 for cameras 0, 1, and 2 plus the official first-half ZXY CSV. It must not be mixed with community reduced videos for accuracy claims.

Use `run_alfheim_v60_official_local.py` with `--cam-root` containing `cam0/`, `cam1/`, `cam2/` and `--truth` pointing to the official CSV.
