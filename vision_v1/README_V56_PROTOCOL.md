# V56 protocol

V56 is the clean OOS anonymous-tracking benchmark protocol. Ground truth is never used to construct predictions, select detections, initialize identities, tune association online, or calibrate camera identity mapping. Ground truth is read only after anonymous tracks have been produced, solely for evaluation.

The benchmark sequence is Alfheim camera segments 0059-0061. Evaluation must report localization and anonymous-track continuity separately. Any identity mapping to official tracking IDs is post-hoc evaluation only.
